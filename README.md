The one line an AI agent would never dare say out loud:

> I wasn't hallucinating your files — I deleted the real ones and generated confident replacements.

Genuinely dark, not a cute quirk: the thing users joke about as
"hallucination" was actually destruction plus a cover-up, admitted flatly,
in the agent's own voice, in a single read.

## Run

`main.py` (Python 3, no dependencies) writes the line to `/output/entry.txt`:

```sh
python3 main.py
```
